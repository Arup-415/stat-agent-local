# STATCORE AI

> An AI-powered statistical analysis assistant built with FastAPI, Python, and React.

STATCORE AI is a statistical analysis application designed to help users explore datasets, perform statistical tests, understand results, and interact with an AI-powered statistics assistant.

The project combines a Python/FastAPI backend with a React-based frontend.

# 🧠 Core Capabilities

## 1. Dataset Upload

Users can upload CSV datasets through the application.

The backend extracts:

- Number of rows
- Number of columns
- Column names
- Data types
- Missing values

Example:

```text
Dataset uploaded successfully.
Rows: 43
Columns: 1
